# Contributing to PowerGrid ZeroOps Lab

Thank you for your interest in contributing! This project is a demo lab for
Azure SRE Agent capabilities, designed for customer demonstrations.

## Getting Started

1. Fork the repo
2. Clone your fork
3. Create a feature branch
4. Make your changes
5. Submit a pull request

## Development Setup

The repo includes a DevContainer configuration for VS Code. Open the repo in
VS Code and select "Reopen in Container" for a pre-configured environment.

## Code Standards

- **Bicep**: Follow [Azure Bicep best practices](https://learn.microsoft.com/azure/azure-resource-manager/bicep/best-practices)
- **Python**: PEP 8
- **JavaScript**: ESLint defaults
- **.NET**: Standard C# conventions
- **Go**: `gofmt`

## What to Contribute

- New break/fix scenarios
- Additional knowledge base runbooks
- Improvements to the CLI simulator
- Documentation fixes
- Bicep module improvements

## Reporting Issues

Use GitHub Issues. Include:
- What you expected
- What happened
- Steps to reproduce
- Azure region and compute platform (ACA/AKS)
